Многофункциональный бот для автоматизации процессов локального сообщества **"5 вёрст в парке Юбилейный | Кстово"**. Бот связывает социальные сети (ВК, Telegram), систему результатов и внутренние таблицы организаторов.

---

## ✨ Основные функции

### 🏁 Управление стартами и результатами
* **Результаты в один клик:** Автоматический мониторинг сайта `5verst.ru`. При появлении протокола бот присылает отчет с количеством финишеров и ссылкой.
* **Благодарность волонтерам:** Парсинг системы NRMS для формирования списка «Команды героев» с указанием ролей.
* **Фото-радар:** Автоматический поиск свежего альбома в группе ВК и прикрепление обложки к посту с результатами.

### 👥 Работа с сообществом
* **VK Tracker:** Бот отслеживает новых подписчиков в группе ВКонтакте и торжественно приветствует их в чате Telegram.
* **Система целей:** Мониторинг роста аудитории с уведомлениями о приближении к важным отметкам (**250, 500, 700, 1000** участников).
* **Иерархия и Титулы:** Синхронизация Telegram-статусов участников с их достижениями в системе 5 вёрст (Новички, Клубы 10, 25, 50, 100 и т.д.).

### 📅 Календарь и Информирование
* **Дни рождения:**
    * 🎉 Ежедневные поздравления именинников.
    * 📅 Анонс дней рождения на неделю (по понедельникам).
    * 🎂 Сводка именинников месяца (каждое 1-е число).
* **Умная Погода:** Прогноз специально на время старта с данными о температуре, осадках и визуальным статусом.
* **Авто-статус ВК:** Обновление даты следующего старта в описании группы и автоматическая корректировка времени мероприятия ВКонтакте.

## 🚀 Настройка и развертывание

Для работы бота необходимо настроить следующие переменные окружения в разделе **GitHub Secrets**:

### Основные токены
* `TELEGRAM_BOT_TOKEN`: Токен от @BotFather.
* `VK_TOKEN`: Токен доступа сообщества ВК.
* `NRMS_USERNAME` / `NRMS_PASSWORD`: Логин и пароль для доступа к системе 5 вёрст.

### ID Чатов и Групп
* `TARGET_CHAT_ID`: ID основного чата участников.
* `ORGS_CHAT_ID`: ID чата организаторов для еженедельной статистики.
* `THREAD_ID`: (Опционально) ID топика в Telegram, если чат разделен на темы.

### Интеграция с таблицами (CSV Export)
* `SHEET_BIRTHDAYS_URL`: Ссылка на экспорт таблицы именинников.
* `SHEET_BASE_URL`: Ссылка на базу данных участников.

## 📊 Запуск модулей

Бот поддерживает запуск отдельных модулей через аргументы командной строки:

```bash
# Обновить титулы участников в чате
python main.py --titles

# Проверить публикацию результатов и отправить отчет
python main.py --results

# Отправить прогноз погоды на субботу
python main.py --weather

# Проверить новых подписчиков в ВК
python main.py --vk-check

# Запустить автоматический цикл поздравлений
python main.py --birthdays-auto
